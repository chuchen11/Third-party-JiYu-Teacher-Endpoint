Release Status

2026.07.31 研究预览版

状态只代表当前测试环境中的证据，不把已发包等同于学生端已执行。

已验证

发现、登录、保活、聊天、缩略图、黑屏、开关机、信息与进程管理

可用

4806/TCP 连续观看、H.264/JPEG 解封装、U/V 色度修正、SPUC 光标解析

部分验证

MCMD mode=2 远程控制，鼠标移动与点击已在当前环境验证

实验性

Core Capabilities

从会话建立到画面与输入

协议实现保留关键字段、传输层级与运行日志，便于对照 IDA 代码和真实报文复核。

01

发现与登录

发送 OONC、CANC、ANNO，并处理 LOGI、KACA、TRMC、DENT 等握手与保活报文。

02

连续屏幕观看

连接 4806/TCP，以 SHCO 选择 UMSP channel 10，解析 TKPC、HHRF/HJRF 和桌面分片。

03

画面还原

使用 bundled FFmpeg 解码 H.264，通过 Pillow/Tk 内嵌显示，并修正学生端交换的 U/V 色度。

04

远程鼠标

用 COMD 承载 MCMD mode=2，发送 28 字节 UDP 输入包，并结合 SPUC 记录校准远端指针。

05

实验性键盘

已实现低级键盘 Hook、VK/扫描码采集和 kind=16 发包；学生端执行效果尚未稳定验证。

06

黑屏与输入锁定

MESS type=0x20 管理黑屏状态，COMD case 6 管理键鼠锁定，并支持定时或手动解锁。

07

学生信息与进程

请求并重组系统信息、进程和窗口列表，支持结束进程、关闭窗口与刷新验证。

08

应用命令

支持聊天、打开网页、远程运行以及带强制或倒计时模式的关机和重启命令。

Protocol Map

控制、画面与输入使用不同通道

连续观看先经 UDP 会话触发，再连接学生端 TCP 服务；远控输入则由 MCMD 建立单独的 UDP 接收端点。

Teacher
UDP 4705 / 5512 · OONC, LOGI, MESS, COMD TCP 4806 · SHCO → TKPC → HHRF / HJRF COMD transaction · MCMD mode=2 UDP input · 28-byte mouse / kind=16 keyboard
Student
224.50.50.42:4705/UDP 主控制、缩略图与 COMD 应用命令通道
225.2.2.1:5512/UDP 登录宣告、MESS 控制、状态广播与信息上报
学生端 4806/TCP 连续观看服务；SHCO 选择 UMSP channel 10
TKPC / HHRF / HJRF 桌面分片外层与 H.264 / JPEG 画面记录
COMD → MCMD 事务命令启动远程输入接收器，默认 Control Student mode=2
28-byte UDP input 鼠标事件已验证；kind=16 键盘事件仍为实验性
SPUC 学生端光标位置记录，用于校准投屏窗口中的远端指针
MESS type 0x20 黑屏状态与提示；COMD case 6/0x0E 负责输入锁定与解锁

Launch

本地运行

需要 Python 3.8+ 和 Windows。请确保教师机与测试学生机处于合法授权的同一网络。

PowerShell 
pip install Pillow imageio-ffmpeg
python "teacher_sim .py"

OpenCV 仅用于可选的 JPEG 显示回退：pip install opencv-python

观看与控制

view_probe <ip> 仅探测 4806/TCP

view <ip> 开始连续观看

view_stop <ip> 停止连续观看

control <ip> 打开远程控制窗口

control_stop <ip> 停止远程控制

mouse <ip> ... 手动发送鼠标事件

key <ip> ... 实验性键盘事件

listpreviewinfopswinskillcloseappopenurlrunblackscreenunlockshutdownrebootmsg

先执行 view_probe。连接失败后等待 60 秒冷却，不要连续重复触发学生端编码器。
